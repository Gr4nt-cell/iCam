iCam stabilization replacement and wide-preview update

Install dependencies: npm install
Typecheck: npm run typecheck
Regression checks: node scripts/check-live-video.cjs; node scripts/check-photo-look.cjs; node scripts/check-photo-smoothing.cjs; node scripts/check-mode-groups.cjs; node scripts/check-rear-screen.cjs; node scripts/check-xiaomi-rear.cjs
Preservation: node scripts/check-ui-preservation.cjs <base-sha> --allow-capture-quality --allow-live-recording --allow-hdr-processing --allow-stabilization-rebuild
Android: npx expo prebuild --platform android --clean --no-install, then android/gradlew :icamera:compileDebugKotlin :icamera:testDebugUnitTest

The old stabilization implementation and dormant post-recording exporters are removed. SteadyFrame.kt contains the replacement. Every native viewfinder fits its stream. SENSOR replaces screen-shaped Full photo cropping; front photos use the selected lens's widest supported zoom at 1x. Hardware common-stream stabilization is preferred, with no stacked software crop. The live fallback processes the current frame with one shared sensor-space transform and small fixed margins. Recording finishes directly without a stabilization export after Stop.

Horizon preserves a fixed crop budget; large tilts may show black corners. HDR keeps the native 10-bit path. The synchronous low-resolution motion readback must be profiled on device. See design/stabilization-validation.md for algorithm, framing policy and limits. Do not treat deterministic tests as proof of iPhone-level stabilization or a tested phone APK.

Rear-screen routes, mirrored selfies, photo smoothing, manual controls and other app features remain included. No signing credentials are distributed.
